01 // INTRODUCTION

1. Executive Summary & Problem Statement

In microgravity spaceflight environments, the absence of natural buoyancy inhibits traditional convective air movement. Electrical arcs, short circuits, or battery overheating inside sealed spacecraft avionics bays form localized, oxygen-starved smoldering pockets. Traditional whole-cabin flooding fire suppression systems introduce excessive toxic residue, cause mission-critical avionics shorting, and require human intervention that incurs prohibitive reaction delay (often > 30 to 90 seconds).

ASAFI (Autonomous Spacecraft Avionics Fire Interceptor) introduces a closed-loop, localized autonomous payload combining edge computer vision (YOLOv11), contactless infrared pyrometry (MLX90614), rapid 2-axis pan-tilt vectoring, and a high-speed 12V micro-solenoid cold-gas valve. Reaction latency is compressed to < 120 milliseconds, neutralizing combustion at ignition without risking peripheral electronics.

02 // ARCHITECTURE

2. System Architecture & Dataflow

The telemetry pipeline utilizes a two-tier verification architecture: Tier 1 (Optical Stream) executes continuous background frame analysis for spatial luminescence anomalies. Upon threshold exceedance, Tier 2 (Infrared Radiometer) takes direct temperature samples while directing the pan-tilt gimbal to align the nozzle vector.

03 // HARDWARE SUITE

3. Detailed Subsystem Specifications

SUBSYSTEM 01

Optical Camera & Vision

  • • Resolution: 640 × 480 @ 15 FPS (VGA)
  • • Field of View: 120° Wide Angle Lens
  • • Architecture: Embedded YOLOv11 Model
  • • Processing Latency: ~20ms per inference
  • • Trigger: Rapid luminescence contour delta
SUBSYSTEM 02

MLX90614 Contactless IR

  • • Target Temp Range: -70°C to +380°C
  • • Ambient Range: -40°C to +125°C
  • • Accuracy: ±0.5°C in room temperature
  • • Resolution: 0.02°C thermal sensitivity
  • • Interface: I2C / SMBus (100 kHz)
SUBSYSTEM 03

Dual-Axis Pan-Tilt Gimbal

  • • Azimuth Sweep: 0° to 180° (Horizontal)
  • • Elevation Sweep: 15° to 90° (Vertical)
  • • Torque: 2.5 kg·cm high-torque metal gear
  • • Slew Speed: 0.10s / 60 degrees
  • • Control: 50Hz PWM Signal
SUBSYSTEM 04

12V Micro-Solenoid Interceptor

  • • Operating Voltage: 12V DC (MOSFET switched)
  • • Actuation Time: < 12ms valve open
  • • Suppressant Gas: Compressed Clean Nitrogen (N2)
  • • Operating Pressure: 100 – 150 PSI
  • • Safety Interlock: 500ms max automatic pulse cutoff
04 // SOFTWARE ALGORITHM

4. Software State Machine & Safety Sequence

STATE 0
SURVEILLANCE / NOMINAL

Continuous YOLOv11 background sampling (640 × 480 @ 15 FPS). Servos stationary at default home position.

STATE 1
ANOMALY CANDIDATE DETECTED

YOLOv11 detects sudden local illumination spike above delta threshold. Bounding box coordinates calculated.

STATE 2
THERMAL CO-VALIDATION & SLEW

Pan-tilt gimbal slews MLX90614 sensor toward calculated target azimuth/elevation. IR reads object temperature. If Temp > 65.0°C, target confirmed.

STATE 3
INTERCEPTION PULSE DISCHARGE

MOSFET gates high for 150ms. 12V valve fires pressurized cold-gas jet directly onto hot spot.

STATE 4
POST-ACTION VERIFICATION

MLX90614 measures cooling rate. If Temp < 45°C, log telemetry event, return gimbal to home, and resume State 0.
